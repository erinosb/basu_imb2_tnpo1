This repository accompanies the manuscript "Differential mRNA localization of karyopherin-β2 homologs in *C. elegans* and humans". This repository contains raw input datasets, original scripts, output plots, output data tables, and reports. By generating this repository, we aim to provide transparency in the data analysis process and to serve as a resource for future studies. Please note that the scripts provided are not intended as executables, but instead as templates. That is, scripts may require path-specific information and additional software, packages, and plugins for full functionality.
